base16384-js

Encode any data as printable Chinese characters in the base16384 format, and decode it back. Plain JavaScript, no dependencies, compatible with the reference command-line tool.

Try it

Use it

import { encodeText, decodeText } from "https://decodeencode.github.io/base16384-js/v1/base16384.mjs";

encodeText("12345678");     // "婌焳廔萷尀㴁"
decodeText("婌焳廔萷尀㴁");    // "12345678"

The module is also at base16384.mjs, which always serves the latest release. Functions, streams and the command-line tool are described in the README, and the format and every difference from the reference tool in FORMAT.md.
